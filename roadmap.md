# Roadmap — Smart-Sayohat yaxshilash rejasi

Davom ettirish: yuklangan namoyish topshirig‘ining birinchi olti bandi ustuvor. Mavjud sahifalar va havolalar saqlanadi.

- [ ] Ismni 2–40 belgi va faqat harflar bilan tekshirish.
- [ ] Katalogni 300 shaxsga kengaytirish va davr filtri.
- [ ] Kviz: 10 savol, 10/20/30 ball, 30 soniyali rejim.
- [ ] Suhbat: ishonchli persona, asosiy ishlar, uch savolli sinov.
- [ ] Tasdiqlangan hikmatlar va eshitish/ulashish.

- [ ] 1. Portretlar: Wikimedia Commons'dan 233 shaxs uchun erkin litsenziyali rasm URL'lari (src/lib/portraits.ts), skeleton + onError fallback avatar, manba/litsenziya shaxs sahifasida
- [ ] 2. Xatolar: og:image faqat leaf routeda (absolute https), hamza slug + redirect, avatar bosh harflari (qavs ignore, HN), dinamik katalog soni, "jadid" kategoriyasi (Munavvar Qori, Behbudiy), har sahifaga unique title/og:description
- [ ] 3. Dizayn/animatsiya: framer-motion — fade-in, card hover lift, hero parallax, suzuvchi yulduzlar, pulsatsiya tugmalar, prefers-reduced-motion
- [ ] 4. Qulaylik: shrift o'lchami tugmalari, yorug'/qorong'i rejim, yuqori kontrast, focus-visible, 44px tugmalar
- [ ] 5. Build + brauzer tekshiruvi
- [ ] 6. Xavfsizlik: paketlar yangilanishi (majburiy)
